# 软件

## 系统装机

### 微 PE

[微 PE](https://www.wepe.com.cn/)

纯净无捆绑的 PE 装机工具，用于系统安装与维护。

### 系统激活

[系统激活](https://cmwtat.cloudmoe.com/cn.html)

CloudMoe（CMWTAT）数字权利激活工具，支持 Windows 与 Office。

### KMS 在线激活

[KMS](https://kms.cx/)

Windows 在线激活（KMS）网站，无需安装软件。

### OTP

[Office Tool Plus](https://otp.landian.vip/zh-cn/)

Office 下载、安装与激活的部署工具。

### HEU KMS Activator

[HEU KMS Activator](https://github.com/zbezj/HEU_KMS_Activator)

开源 KMS 激活工具，支持 Windows 与 Office。

### VC++ 运行库

[vcredist](https://github.com/abbodi1406/vcredist)

微软 Visual C++ 运行库合集，一次性补齐各版本依赖。

## 效率工具

### uTools

[uTools](https://www.u-tools.cn/)

插件化效率启动器，支持搜索、翻译、计算等。

### Snipaste

[Snipaste](https://zh.snipaste.com/)

截图工具，支持贴图到屏幕、取色与标注。

### PixPin

[PixPin](https://pixpinapp.com/)

截图贴图工具，支持长截图与 OCR 文字识别。

### PicGo

[PicGo](https://molunerfinn.com/PicGo/)

图床上传工具，配合 Markdown 使用。

## 文件与卸载

### Bandzip

[Bandizip](https://www.bandisoft.com/)

压缩解压工具，支持多种格式，速度快。

### Geek

[Geek Uninstaller](https://geekuninstaller.com/)

轻量卸载工具，可彻底清理注册表与残留文件。
