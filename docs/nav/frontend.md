# 前端资源

### TresJS

[TresJS](https://tresjs.org/)

基于 Three.js 的 Vue 声明式 3D 库，用组件方式构建 WebGL / WebGPU 场景。

### Payload

[Payload](https://payloadcms.com/)

基于 Next.js 的开源全栈 Headless CMS / App 框架，代码定义 Schema。

### CSS-Tricks

[CSS-Tricks](https://css-tricks.com/)

前端设计与开发教程站，含 CSS 指南、Almanac 及大量技巧文章。

### VibeHub

[VibeHub](https://vibe-hub.org/)

Vibe Coding 术语与需求表达指南，用自然语言描述前端/后端/设计需求。

### MotionSites

[MotionSites](https://motionsites.ai/)

AI 建站提示词库，面向 Lovable、Bolt、Cursor、Claude 的落地页与 3D 网站 Prompt。

### UI Colors

[UI Colors](https://uicolors.app/generate)

Tailwind CSS 配色生成器，可视化生成 color scale 并在组件上预览。
