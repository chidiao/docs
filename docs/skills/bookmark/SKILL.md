# 收藏

用户说「收藏」并给出网址时，按此流程收录到 `/nav/`。

## 流程

1. **判断类型**：
   - IDE / 编辑器插件（如 VSCode Marketplace 等插件链接）→ 追加到 `nav/ide-plugin.md`。
   - 其他网站 → 归入 `/nav/` 现有类目：
     - 资源 → `nav/resource`（二级分类：资源站 / 游戏）
     - 软件 → `nav/software`（二级分类：系统装机 / 效率工具 / 文件与卸载 / 网络工具 / 影音壁纸）
     - 开发 → `nav/develop`（二级分类：运行时与工具 / 编辑器 / 数据库 / 前端 / 文档与教程 / AI 建站）
     - 项目 → `nav/project`（开源/参考项目仓库）
2. **获取信息**：用 `webfetch` 访问网址，确认名称与用途，名称以站点/插件标题为准。
3. **追加条目**：按「[链接条目](/skills/link-entry/SKILL)」写入对应文件：`### 标题` + `[名称](地址)` + 简介。
4. **更新导航**：仅当新增类目时才改动 `nav/index.md`、`nav/sidebar.ts`。
5. **构建验证**：运行 `pnpm docs:build`。

## 约定

- 不盲目新增类目；现有类目都不合适时先问用户。
- 标题用简短名称，链接名称可用正式称呼，简介一句话。
